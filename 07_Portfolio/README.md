# NovaMart Retail Business Performance Analytics — Portfolio

This folder contains the portfolio-ready presentation and supporting materials for the NovaMart Retail Business Performance Analytics project.

## Portfolio Objective

Present the complete retail analytics case study in a clear, professional, and recruiter-friendly format.

## Project Coverage

- Business problem and objectives
- Data source and data preparation
- Data quality and cleaning
- KPI development
- Sales and profitability analysis
- Product and category analysis
- Regional analysis
- Customer analysis
- Discount analysis
- Excel dashboard
- Business insights
- Recommendations
- Executive summary

## Portfolio Standard

The project demonstrates an end-to-end analytical workflow from raw transactional data to business recommendations.

All reported findings should be traceable to the validated project outputs.
