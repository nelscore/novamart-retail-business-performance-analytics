# NovaMart Retail Business Performance Analytics — Data

This folder contains the datasets used in the project.

## Data Structure

- `Raw/` — Original source dataset preserved without analytical modifications.
- `Cleaned/` — Validated and cleaned dataset prepared for analysis.

## Data Workflow

Raw Source Data
→ Data Quality Checks
→ Cleaning
→ Validation
→ Cleaned Dataset
→ Analysis

## Data Governance

- The original raw dataset will be preserved.
- Cleaning will be performed on a separate copy.
- No raw records will be overwritten.
- Derived fields will be documented.
- Data-quality issues and their treatment will be documented.
- Analytical results will be based on validated data.

## Data Classification

### Source Data
Original dataset obtained from the selected public retail data source.

### Cleaned Data
Dataset produced after documented data-quality and cleaning procedures.

### Derived Data
Fields and metrics calculated from the source data for analytical purposes.
