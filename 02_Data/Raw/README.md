# Raw Data

## Data Source

This project uses Tableau's Sample Superstore dataset as the underlying
source data for the analysis.

Official source:
https://public.tableau.com/app/resources/sample-data

Dataset:
Superstore Sales

## Dataset Context

Tableau provides Superstore as sample data representing a fictitious
retail company.

The dataset contains information related to products, customers, sales,
profitability, geography, dates, categories, and other retail
transaction attributes.

## Project Usage

The dataset is used as the underlying data source for the
NovaMart Retail Business Performance Analytics case study.

NovaMart Retail is a fictional business scenario created for portfolio
demonstration purposes.

## Data Redistribution

The original source dataset is not redistributed in this public
repository.

The raw source file should be obtained directly from Tableau's official
Sample Data resource when required for reproducing the analysis.

## Data Workflow

Source Dataset

→ Analysis

## Reproducibility Note

Analysis outputs in this repository are derived from the source dataset
