# NovaMart Retail Business Performance Analytics — Documentation

This folder contains the supporting documentation, data definitions, data-quality evidence, KPI definitions, project documentation, and final validation records for the NovaMart Retail Business Performance Analytics project.

## Documentation Contents

- `03_data_dictionary.csv` — Data field definitions and business descriptions.
- `04_data_quality_report.csv` — Data-quality checks and validation results.
- `05_kpi_definitions.csv` — KPI definitions, formulas, and business interpretation.
- `18_project_documentation.pdf` — Detailed project methodology and documentation.
- `21_final_QA_validation.csv` — Final quality assurance and validation results.

## Documentation Principle

All documentation is based on the project data, analytical workflow, calculations, and validation performed during the project lifecycle.
