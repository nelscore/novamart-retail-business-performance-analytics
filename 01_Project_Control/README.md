# NovaMart Retail Business Performance Analytics — Project Control

## Project Purpose

This project analyzes retail business performance using real-world retail transaction data and Excel-based analytics.

The objective is to transform raw transactional data into reliable business insights covering:

- Sales performance
- Profitability
- Product performance
- Category and subcategory performance
- Regional performance
- Customer performance
- Discount effectiveness
- Business growth trends

## Business Case

NovaMart Retail is a fictional multi-category retail business used for portfolio and analytical case-study purposes.

The analysis is designed from the perspective of a Data Analyst supporting business and management decisions.

## Analytical Workflow

Raw Data
→ Data Quality
→ Data Cleaning
→ Data Transformation
→ KPI Development
→ Business Analysis
→ Excel Dashboard
→ Insights
→ Recommendations
→ Validation & QA
→ Final Portfolio

## Project Principles

- Use actual source data wherever available.
- Preserve the original raw dataset.
- Never fabricate analytical results.
- Clearly distinguish source data, calculated metrics, assumptions, and derived fields.
- Validate important calculations before presenting insights.
- Focus on business decisions, not only visualizations.
- Keep the project reproducible and professionally documented.
