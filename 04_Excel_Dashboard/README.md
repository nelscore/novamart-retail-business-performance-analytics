# NovaMart Retail Business Performance Analytics — Excel Dashboard

This folder contains the final Excel-based business intelligence and dashboard deliverables for the NovaMart Retail Business Performance Analytics project.

## Dashboard Objective

Transform validated analytical outputs into an executive-friendly Excel dashboard that supports business decision-making.

## Dashboard Scope

The Excel dashboard will cover:

- Executive KPI overview
- Sales performance
- Profitability
- Category and subcategory performance
- Product performance
- Regional performance
- Customer performance
- Discount effectiveness
- Business trends
- Key business insights

## Source Data

Primary analytical source:

`02_Data/Cleaned/02_cleaned_dataset.csv`

Supporting analytical outputs:

`03_Analysis/`

## Dashboard Structure

1. Executive Overview
2. Sales Performance
3. Product Performance
4. Customer & Segment Analysis
5. Profitability & Discount Analysis
6. Regional Performance
7. Business Insights

## Dashboard Principles

- Use validated data only.
- KPIs must reconcile with analytical outputs.
- No fabricated business results.
- Charts must have clear business purpose.
- Metrics must be reproducible.
- Dashboard design should be executive-friendly.
- Insights must be supported by calculated evidence.

## Deliverables

The completed folder will contain:

- Final Excel dashboard workbook
- Supporting calculation sheets
- KPI summary
- Dashboard documentation
- Final dashboard screenshots
- Dashboard QA validation

## Workflow

Cleaned Dataset → Analytical Outputs → KPI Layer → Excel Calculations → Dashboard → Insights → QA
