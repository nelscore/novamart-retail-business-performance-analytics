# NovaMart Retail Business Performance Analytics — Analysis

This folder contains analytical outputs generated from the validated cleaned dataset.

## Analysis Objective

Analyze retail business performance across:

- Sales performance
- Profitability
- Product performance
- Category and subcategory performance
- Regional performance
- Customer performance
- Discount effectiveness
- Business growth trends

## Source Dataset

Primary analytical source:

`02_Data/Cleaned/02_cleaned_dataset.csv`

## Analysis Workflow

Cleaned Dataset → KPI Calculation → Exploratory Analysis → Business Analysis → Analytical Outputs → Insights

## Analytical Principles

- Use validated data as the primary source.
- All metrics must be calculated from the dataset.
- No business result will be fabricated.
- Calculated metrics must be reproducible.
- Findings must be separated from assumptions.
- Recommendations must be supported by analytical evidence.
